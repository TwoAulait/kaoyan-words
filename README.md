# 考研英语背单词（坚果云同步版）

一款面向考研英语的个人背单词软件：**Windows 桌面版** + **安卓客户端**，两端通过 **坚果云网盘（WebDAV）** 在任意网络下手动同步学习进度和生词本（打开时询问是否获取、主页面「☁ 上传」「☁ 从云端获取」手动同步、退出时确认未上传改动），本地另存最近 10 份自动备份，双保险。没有网络时用「导出/导入备份」文件迁移数据。

- 词库：**5493** 个考研英语词汇（单词 / 注音 / 释义，来自乱序词表）
- 双端：Windows 用 tkinter 桌面程序；安卓用 WebView 外壳（纯平台 API，无第三方依赖）
- 同步：坚果云 WebDAV 网盘同步（唯一方式，全手动）——打开时询问是否从云端获取、主页面「☁ 上传」「☁ 从云端获取」按钮手动同步并显示上次同步时间、本机有改动未上传时红字警示、退出时若有未上传改动会确认；每次上传/获取前都会先显示云端与本机的进度、生词数再让你确认（其余操作不联网）
- 备份：两端通用的 JSON 备份文件，外加自动本地备份（各保留最近 10 条）

## 功能

| 功能 | 说明 |
| ---- | ---- |
| 单词学习 | 逐词浏览，进度自动保存，进度条 + 「第 X / 5493」指示 |
| 认识 / 不认识 | 「不认识」记入生词本，「认识」从生词本删除；两键都自动跳下一个 |
| 生词本 | 顶部「生词本 N 词」进入，可逐条删除或一键清空 |
| 坚果云同步 | 电脑与手机共用同一 WebDAV 文件：全手动——打开时询问是否获取，主页面「☁ 上传」「☁ 从云端获取」手动同步（带上次同步时间），有改动未上传时红字警示，退出时若有未上传改动会确认；每次上传/获取前先显示云端与本机的进度、生词数再确认，见下文 |
| 本地备份 | 每次操作时自动把进度+生词存成本地备份（不联网），两端各保留最近 10 条，可恢复 |
| 导出 / 导入备份 | 两端通用的 JSON 备份，外出没网时用来迁移数据 |

## 快速开始

### Windows 版
直接运行 `release/考研英语背单词.exe`（已内置词库，双击即可，无需安装）。首次运行会在 exe 同目录自动创建数据文件：
- `学习进度.txt` —— 当前学到第几个词
- `不认识的单词.xls` —— 生词本（一个「单词」工作表：序号/单词/注音/释义）
- `本地备份/` —— 每次操作/关闭时自动生成的进度+生词快照（保留最近 10 份）

### 安卓版
把 `release/考研英语背单词.apk` 发到手机安装（提示「未知来源」时允许即可）。首次安装/升级打开会提示：**请先在电脑端配置好坚果云同步并点「☁ 上传」上传一次**，再把同一个地址填到手机设置页；打开手机 app 时会询问「是否从云端获取」，选确定即可拿到云端数据。

### 坚果云网盘同步（唯一同步方式，全手动，无需同一 WiFi）
电脑与手机共用坚果云网盘里的**同一个 WebDAV 文件**。同步全部由你手动触发，绝不偷偷联网或覆盖数据，任意网络都能同步：

1. 免费注册坚果云（www.jianguoyun.com），在网页端生成**应用密码**（不是登录密码）：账户 → 安全 → 应用密码；
2. 在坚果云里新建一个文件夹（如 `kaoyan_backup`）；
3. 两端都填写**同一个地址**：
   - Windows 版：软件下方「坚果云同步设置」→ 填地址 / 用户名 / 应用密码；
   - 安卓版：⚙ 设置 → 坚果云网盘同步 → 填同样的三项。
   - 地址形如：`https://dav.jianguoyun.com/dav/kaoyan_backup/kaoyan.json`（即 `kaoyan_backup` 文件夹下的 `kaoyan.json`）；
4. 点「保存配置」，之后按三种时机手动同步：
   - **打开软件 / 手机 app**：弹窗询问「是否从云端获取最新数据」→ 选「是」把云端拉到本端；
   - **想上传**：电脑端点底部绿色「☁ 上传」按钮；手机端点主页面「☁ 上传」按钮；
   - **想获取**：两端在「上传」按钮旁都有「☁ 从云端获取」按钮，点它把云端拉到本端；
   - **退出时**：若有改动还没上传到云端，会弹窗让你选「先上传再退出 / 直接退出 / 继续学习」。
5. 每次上传或获取前，都会先读取云端并弹窗显示**云端当前 vs 本机当前**的进度和生词数
   （如「云端当前：第 980/5493 词，生词 9 个　本机当前：第 1200/5493 词，生词 15 个」），
   让你再次确认后再执行。
6. 本机有改动还没上传到云端时，两端主页面都会**红字警示**「有改动未上传」。

**同步规则**：手动同步，其余操作不联网。若云端还没有数据（或为空），获取时本端保留自己，不会误清空。

**本地备份**：电脑每次操作/关闭、手机每次操作时，自动把当前进度和生词存成一份快照（两端都不联网），各保留最近 10 条。电脑端在 exe 旁 `本地备份/` 文件夹里，软件底部「本地备份」按钮可查看并恢复；手机端在设置页「本地备份」里可一键恢复。云端出错时用最近备份即可找回。

> ⚠ 同一时刻只在一端操作：云端只有一份文件，**谁最后上传以谁为准**。电脑与手机请勿同时操作。

## 数据说明

- `学习进度.txt`、`不认识的单词.xls`、`网盘同步配置.txt`（坚果云账号配置）、`本地备份/` 是**运行时自动创建的用户数据**，不在本仓库内（见 `.gitignore`）；删除进度/生词文件会被当作重新开始。
- 词库 `02.考研英语词汇乱序版.xls` 为考研英语乱序词汇表，仅供学习参考；如需商用/再分发请自行确认词表来源与授权。

## 从源码构建

### Windows 版（PyInstaller）
```bash
pip install xlrd xlwt pyinstaller
python -m PyInstaller --onefile --windowed --name kaoyan_words kaoyan_words.spec
# 产物：dist/kaoyan_words.exe → 重命名为 考研英语背单词.exe
```

### 安卓版（Gradle + Android SDK）
工具链（2026-08 验证兼容）：JDK 21 + Android SDK（`platforms;android-35`、`build-tools;35.0.0`）+ Gradle 8.9 + AGP 8.7.3。`compileSdk 35 / minSdk 24`，纯平台 API，不引入 AndroidX。

```bash
cd android
# 先新建 local.properties 填本机 SDK 路径，例如：sdk.dir=C:/Android
gradle assembleDebug --offline
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

> 中文/非 ASCII 路径下 aapt2 偶发编码错误：若构建报错，把工程放到纯 ASCII 路径（如 `C:\build\android`）再构建，产物拷回即可。
> 更换词库后，用 `python tools/make_words_js.py` 重新生成 `android/app/src/main/assets/words.js` 再打包。

## 常见问题

- **认识 / 不认识什么意思？** 认识：从生词本删除（若在）；不认识：记入生词本（幂等）；两键都自动跳下一个。
- **手机升级/重装后数据丢了吗？** 手机端首次打开会提示先配置坚果云；配置好后打开 app 会询问是否从云端获取，选「是」即可拿回数据，无需手动导入。
- **坚果云同步失败？** 检查：地址/用户名/应用密码三项两端是否一致、地址是否正确到 `kaoyan.json`、坚果云里是否建了对应文件夹、应用密码是否输错（不是登录密码）。电脑端可在「坚果云同步设置」点「测试连接」；手机端可在设置页点「测试连接」看具体报错。
- **云端数据坏了/被覆盖怎么办？** 用本地备份找回：电脑端点「本地备份」恢复最近一份；手机端在设置页「本地备份」里恢复。
- **没网能继续用吗？** 能。没网时程序不拉取云端，仅本地使用，学习进度照常保存；重连后打开 app 时选「是否从云端获取」，或点「☁ 上传」「☁ 从云端获取」即可补同步。
